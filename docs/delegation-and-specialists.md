# Delegation and specialists

Frontier represents delegation as a bounded plan before any execution. Only the allowlisted research, engineering, reviewer, and data specialist roles are accepted; each role appears once and a plan contains at most eight tasks. Every task has a stated objective and evidence label.

Planning does not invoke a subagent, connector, shell, browser, or provider. A task marked with side effects requires explicit approval and remains a plan until an execution boundary authorizes it.
